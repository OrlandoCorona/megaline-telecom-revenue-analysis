# Datasets

El análisis utiliza cinco archivos CSV con datos de uso del operador ficticio
**Megaline** (diciembre 2018):

| Archivo | Descripción |
|---|---|
| `megaline_users.csv` | Información de los 500 usuarios (plan, ciudad, alta/baja). |
| `megaline_calls.csv` | Registro de llamadas (id, usuario, fecha, duración). |
| `megaline_messages.csv` | Registro de mensajes enviados. |
| `megaline_internet.csv` | Sesiones de internet (MB consumidos). |
| `megaline_plans.csv` | Condiciones de los planes Surf y Ultimate. |

Los cinco archivos están incluidos en esta carpeta, por lo que el notebook es reproducible directamente.
